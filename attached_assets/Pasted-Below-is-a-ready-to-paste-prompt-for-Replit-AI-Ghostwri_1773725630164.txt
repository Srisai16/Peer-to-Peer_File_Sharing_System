

```javascript

```

* Remove hardcoded localhost URLs.

* Ensure frontend builds correctly using:

```
npm run build
```

## 2. Unlimited File Size Transfer

Modify file transfer logic to support extremely large files (10GB+).

Requirements:

Replace FileReader logic with streaming:

* Use `file.stream()` and `ReadableStream`
* Send chunks sequentially
* Prevent memory overflow

Chunk transfer strategy:

```javascript
const CHUNK_SIZE = 64 * 1024;
```

Implement buffer control:

```javascript
while (dataChannel.bufferedAmount > 8 * 1024 * 1024) {
  await new Promise(r => setTimeout(r, 10));
}
```

Ensure the sender never overfills the WebRTC send buffer.

